# Feedback website Captain John

Gebruik dit formulier voor een bug, idee, vraag of compliment.
Een screenshot van het scherm waarop je de knop indrukte, gaat automatisch mee.

Dit formulier volgt dezelfde bouwstenen als een Google Formulier: **één keuze**, **meerdere keuzes** en **vrije tekst**. Pas dit bestand aan om vragen te wijzigen.

## Wat voor reactie wil je geven?
type: radio
required: true

- Er werkt iets niet
- Ik heb een verbeteridee
- Ik heb een vraag
- Een compliment

## Hoe tevreden ben je over de website?
type: radio
required: true

- Zeer tevreden
- Tevreden
- Neutraal
- Ontevreden
- Zeer ontevreden

## Over welk onderdeel gaat het?
type: checkbox
help: Je mag meerdere onderdelen aankruisen.

- Homepage / overzicht
- Projectpagina
- Foto's en lightbox
- Verkoophoekje
- Inloggen of account
- Project bewerken
- Iets anders

## Licht je reactie toe
type: text
required: true
rows: 6
placeholder: Wat gebeurde er, of wat zou je willen zien?

## Mag Captain John je benaderen over deze reactie?
type: radio
required: true

- Ja
- Nee, anonieme feedback is prima
